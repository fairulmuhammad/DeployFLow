## Create / touch
- Laravel 13 skeleton, `config/deployflow.php`, `.env.example` from `CONFIGURATION.md`.
- `docker-compose.yml` + `infrastructure/compose/` (postgres, redis, minio, registry, traefik).
- `Makefile` with the commands in `AGENTS.md` §6.
- `.github/workflows/ci.yml`, `security.yml`.
- Frontend base: Vite, React 19, TS strict, Tailwind 4, Inertia root layout.
- `docs/` link check; fix any broken references.

## Contracts
None beyond the config schema and docs. Do not invent APIs.

## Exit proof
- `make setup && make check` on a clean clone.
- `docker compose config` valid.
- `/up` 200; `/healthz` 200 with DB + Redis.
- CI green on a PR.
- No service except `deploy-agent` is allowed a Docker socket (agent arrives in M5; compose may omit it now).

## Guardrails
- No domain models, no deployment code, no GitHub client.
- Do not add dependencies outside the pinned stack.
- Do not create a second frontend build pipeline.
