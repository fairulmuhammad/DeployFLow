# M4 — Build Pipeline

## Objective
Turn an authorized commit into a verified digest, inside the isolation boundary.

## Read first
`docs/WORKER-CONTRACTS.md` §2–§5, §12; `docs/SECURITY.md` §7–§8; ADR-006, ADR-013, ADR-018; `docs/TESTING.md` FT-01…07.

## Tasks
DF-015, DF-016, DF-017, DF-018 (a–e), DF-019, DF-020.

## Create / touch
- `workers/contracts/*.schema.json` + fixtures + contract test.
- `app/Domain/Workers`, `app/Infrastructure/Execution` (auth, claim, leases, reaper).
- `workers/build-worker/`: workspace lifecycle, rootless BuildKit, registry push, log upload, signal handling.
- `app/Infrastructure/Registry/` gateway + local adapter.
- `app/Infrastructure/Storage/` log store + redaction.

## Contracts
Job/claim/step/log/complete payloads; digest format; error codes per step.

## Exit proof
- End-to-end: authorized repo → image in registry → digest recorded.
- FT-01…07 pass.
- Workspace removed on success, failure, timeout, cancel.
- No runtime secret in the build environment; build args allowlisted.
- Duplicate claim impossible (partial unique index proven).

## Guardrails
- No Docker socket, no privileged containers, no host network.
- Do not log env values, headers, or signatures.
- Do not build on the control-plane host.
- No tag-based artifact accepted.

## Handoff
Publish the working build-worker run command and required host capabilities in `DEPLOYMENT.md`.
