# M1 — Identity and Tenancy

## Objective
Organizations are isolated by construction, proven by tests, before any tenant data exists.

## Read first
`docs/PRD.md` §3, `docs/DATA-MODEL.md` §4, `docs/SECURITY.md` §3–§4, `docs/API.md` §2–§3, ADR-015.

## Tasks
DF-005, DF-006, DF-007, DF-008.

## Progress

- [x] **DF-005 — Authentication.** Session login/logout, email verification, password reset, profile updates, the
  `API.md` §6 throttles, UUIDv7 `users`, and JSON error envelopes for 401/422/429. Identity model lives at
  `app/Domain/Identity/Models/User.php`; actions in `app/Application/Actions/Identity`.
  Evidence: `tests/Feature/Auth/*` (31 auth tests; 35 with the existing suite, 154 assertions), `pint --test`,
  `phpstan` level 8, `tsc --noEmit`, `npm run build`.
- [x] **DF-006 — Organizations.** Create/update/soft-delete, slug rules, owner invariant, invitations, member roles,
  owner transfer, exactly-one-owner test.
- [x] **DF-007 — RBAC.** Policies for every model, `RolePermission` truth table, `ResolveOrganization` + `EnsureRole`,
  `AuthorizationMatrixTest`.
- [x] **DF-008 — Tenant isolation.** `TenantContext` (scoped container binding), the `BelongsToOrganization` global
  scope that throws `TenantContextMissing`, scoped `{member}`/`{invitation}` route bindings, a tenant-safe
  organization list, and `tests/Security/TenantIsolationTest` (SEC-01…03, SEC-19) plus the missing-context and
  `withoutScope` cases. Evidence: 76 Pest tests / 335 assertions, `pint --test`, `phpstan` level 8, `tsc --noEmit`.

## Exit proof
- `tests/Security/TenantIsolationTest` proves the global scope, the missing-context failure, and the `withoutScope`
  escape, and covers every tenant-owned model that exists in M1 (members, invitations, audit logs) with SEC-01…03 and
  SEC-19. Application/environment/deployment/variable/log cases are added with their models (DF-012, DF-013, DF-021,
  DF-026).
- `AuthorizationMatrixTest`: every policy method allow + deny.
- Removing a member denies the next request immediately.
- Exactly-one-owner test; owner transfer updates both rows in one transaction.

## Guardrails
- No `withoutGlobalScope` outside the allowed list in `SECURITY.md` §3.
- No organization ID accepted from request input.
- Do not add a public API token mechanism.

## Handoff
Note any new invariant in `AGENTS.md` and add its test mapping to `SECURITY.md` §16.
