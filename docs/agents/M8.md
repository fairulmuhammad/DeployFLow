# M8 — Release and Documentation

## Objective
Someone else can reproduce the installation and watch the acceptance demo succeed.

## Read first
`docs/DEPLOYMENT.md`, `docs/OPERATIONS.md`, `docs/PRD.md` §10, `docs/ROADMAP.md` M8.

## Tasks
DF-034.

## Create / touch
- Control-plane, build-worker, deployment-agent, migrate images + SBOM + scan.
- Staging and production compose/manifests; secret wiring; backups.
- Smoke script and release workflow (`release.yml`).
- Demo repository with a good commit and a broken commit.
- Release notes, screenshots, known limitations, upgrade guide.

## Exit proof
- PRD §10 acceptance script executed end-to-end by someone other than the author, with deployment IDs and screenshots.
- Queue workers restart gracefully; migrations are expand/contract.
- A second developer completes the quickstart without help.
- Rollback of the control plane is demonstrated (previous digest).

## Guardrails
- No secrets in images, compose files, or release notes.
- No release without the full `DEPLOYMENT.md` §10 checklist.
- Do not tag `v1.0.0` before the failure suite and security review are green.

## Handoff
Freeze `docs/` for the release; open a post-v1 backlog from `PRD.md` P1/P2 items.
